# AgentRouter

На телефоне: Settings → Providers. Provider ID `agentrouter`,
URL `https://agentrouter.org/v1`, API format `Responses`.
Вписать ID моделей, включённых в вашем аккаунте, и ключ в поле API key.
Нажать Save, затем выбрать модель в композере.

На ПК реально ответила модель `gpt-5.6-sol` существующего провайдера
`AgentRouter-gpt-responses-gateway` через Responses. `gpt-6.1-sol` также
присутствует в его настройках, но ответ этой модели не проверялся.
Новый `agentrouter` зарегистрирован через настоящий opencode без ключа;
для запросов под новым ID ключ вводит сам пользователь.

Ключ уходит в PUT `/auth/{id}`, хранится самим opencode и не сохраняется
в HTML, localStorage или Git. Пустое поле сохраняет существующий ключ.
Настройки (без ключа) идут в PATCH `/global/config` и действуют для всех
проектов. Клиент проверяет появление провайдера в `/config/providers`.
PATCH `/config` не используется: в 1.19.3 его файл проекта не подхватывается
загрузчиком. Заголовки провайдера не настраиваются и не подменяются.
